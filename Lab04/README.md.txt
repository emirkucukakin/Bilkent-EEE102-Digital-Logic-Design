# Lab 04 — Arithmetic Logic Unit

Laboratory work completed for **EEE102: Digital Logic Design** at Bilkent University during **Spring 2026**.

**Author:** Emir Küçükakın

## Overview

This experiment explores an arithmetic logic unit (ALU), including arithmetic, bitwise logic, shifting, and selection operations.
