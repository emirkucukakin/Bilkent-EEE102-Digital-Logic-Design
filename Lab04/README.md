# Lab 04 — Arithmetic Logic Unit

**EEE102: Digital Logic Design — Bilkent University, Spring 2026**

**Author:** Emir Küçükakın

## Overview

This experiment focuses on designing an arithmetic logic unit (ALU) with arithmetic, bitwise logic, shifting, and selection operations.

The design combines individual modules into a complete digital system using Vivado.
