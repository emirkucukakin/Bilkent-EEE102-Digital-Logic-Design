# Lab 05 — Counter and Seven-Segment Display

**EEE102: Digital Logic Design — Bilkent University, Spring 2026**

**Author:** Emir Küçükakın

## Overview

This experiment implements a hexadecimal counter and seven-segment display controller using VHDL.

The design includes counter logic, hexadecimal decoding, display scanning, and top-level integration.
