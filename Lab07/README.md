# Lab 07 — Door Lock Finite State Machine

**EEE102: Digital Logic Design — Bilkent University, Spring 2026**

**Author:** Emir Küçükakın

## Overview

This experiment explores a door lock controller based on a finite state machine.

The work covers state transitions, sequential logic, and the physical implementation and testing of the controller.

## Contents

The laboratory report presents the state machine design, circuit implementation, and experimental results.
